# Code

Phần agent, gọi model và truy xuất dữ liệu thật được triển khai trong [starter/agentic.py](../starter/agentic.py); TF-IDF trong [starter/baseline.py](../starter/baseline.py); tổng hợp đánh giá trong [starter/agent_metrics.py](../starter/agent_metrics.py).

Thư mục này giữ các phần hỗ trợ cần thiết: `settings.py` đọc cấu hình; `embeddings.py` mã hóa query tương thích Day 6; `prepare.py` xuất snapshot và benchmark; `run.py` nối CLI, kiểm tra dữ liệu và ghi trace. [Hướng dẫn chạy](../starter/README.md#bài-thực-hiện-của-phạm-cát-tân).
